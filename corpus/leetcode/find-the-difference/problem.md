# Find the Difference

## Problem

You are given two strings `s` and `t`. String `t` is generated by taking string `s`, shuffling it, and then adding **one extra character** at a random position. Return the character that was added to turn `s` into `t`.

You may assume:
- `0 <= len(s) <= 1000`
- `len(t) == len(s) + 1`
- `s` and `t` consist of lowercase English letters.

## Function Signature

```clojure
(defn solve [s t] ...)
```

## Input

Read a single test case from standard input in the following form:

```
CASE0=s=hello
CASE0=t=helollo
CASE0=expected=a
```

The fields are:
- `s` — the original string
- `t` — the string with one extra character
- `expected` — the single character that was added (provided for verification)

## Output

Print a single line containing the character that was added to `s` to produce `t`.

## Example

```
Input:
CASE0=s=abcde
CASE0=t=abecdfe

Output:
f
```

## Notes

- A frequency-count approach works in O(n) time using O(1) extra space (since the alphabet is bounded to 26 letters).
- The XOR trick (`xor all chars of s` and `t`) also yields the added character in O(n) time and O(1) space.
